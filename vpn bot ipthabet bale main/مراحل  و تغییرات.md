\# 📋 خلاصه کامل تمام کارهایی که انجام شده



\## ۱. 🔄 تمدید اشتراک (تمدید روز)



\### دکمه‌ها:

\- در \*\*حساب من\*\* → دکمه \*\*«🔄 تمدید اشتراک»\*\* (فقط وقتی اشتراک فعال دارید نمایش داده می‌شود)



\### متن‌ها:

```

🔄 تمدید اشتراک



📂 دسته‌بندی: 💎 VIP

📊 حجم: ۱۰ گیگابایت

💰 هزینه تمدید ۶۰ روزه: ۸۰,۰۰۰ تومان



پس از تایید، زمان اشتراک شما تمدید خواهد شد.

```



\### منطق:

1. کاربر روی «تمدید اشتراک» کلیک می‌کند

2\. حجم فعلی × نرخ دسته = مبلغ تمدید

3\. سفارش با `order\_type='renew'` ساخته می‌شود

4\. کاربر فیش می‌فرستد → ادمین تایید می‌کند

5\. \*\*در دیتابیس:\*\* `extend\_subscription` → ۶۰ روز به تاریخ انقضای فعلی اضافه می‌شود (اگر هنوز فعال باشد)

6. \*\*در پنل PasarGuard:\*\* `update\_user\_expiry` → تاریخ انقضا در پنل هم تمدید می‌شود (با حفظ حجم فعلی)



\---



\## ۲. 📈 افزایش حجم اشتراک



\### دکمه‌ها:

\- در \*\*حساب من\*\* → دکمه \*\*«📈 افزایش حجم»\*\* (فقط وقتی اشتراک فعال دارید)

\- بعد از کلیک: دکمه‌های \*\*➕ ۵ / ۱۰ / ۲۰ / ۵۰ گیگ\*\* + \*\*✏️ حجم دلخواه\*\*



\### متن‌ها:

```

📈 افزایش حجم اشتراک



📂 دسته‌بندی: 💎 VIP

📊 حجم فعلی: ۱۰ گیگابایت

💰 نرخ: ۸,۰۰۰ تومان/گیگ



مقدار حجم اضافه را انتخاب کنید:

```



\*\*مرحله تایید (دو مرحله‌ای):\*\*

```

🧾 تایید افزایش حجم



📂 دسته‌بندی: 💎 VIP

📊 حجم فعلی: ۱۰ گیگابایت

➕ حجم اضافه: ۲۰ گیگابایت

📊 حجم نهایی: ۳۰ گیگابایت

💰 مبلغ: ۱۶۰,۰۰۰ تومان



آیا تایید می‌کنید؟

```



\### منطق:

1. کاربر حجم اضافه را انتخاب می‌کند (آماده یا دلخواه)

2. \*\*تایید نهایی\*\* با نمایش حجم فعلی + اضافه + نهایی + مبلغ

3\. سفارش با `order\_type='add\_volume'` ساخته می‌شود

4\. کاربر فیش می‌فرستد → ادمین تایید می‌کند

5\. \*\*در دیتابیس:\*\* `extend\_subscription\_volume` → حجم فعلی + حجم اضافه

6\. \*\*در پنل PasarGuard:\*\* `add\_user\_volume` → حجم در پنل هم افزایش می‌یابد (با verify که واقعاً تغییر کرده)



\---



\## ۳. ✏️ حجم دلخواه در دو مرحله (خرید جدید)



\### قبل:

کاربر عدد می‌نوشت → مستقیم سفارش ساخته می‌شد



\### حالا (دو مرحله‌ای):

\*\*مرحله ۱:\*\* کاربر عدد حجم را می‌نویسد

\*\*مرحله ۲:\*\* پیام تایید نمایش داده می‌شود:

```

🧾 تایید سفارش



📂 دسته‌بندی: 💎 VIP

📊 حجم: ۳۵ گیگابایت

💰 نرخ: ۸,۰۰۰ تومان/گیگ

⏱ مدت: ۶۰ روزه

💰 مبلغ: ۲۸۰,۰۰۰ تومان



آیا تایید می‌کنید؟

```

دکمه \*\*«✅ تایید و ادامه»\*\* → پیش‌فاکتور و پرداخت

\## ۶. 📊 دستورات ادمین

|-------|-----|

| `/stats` | آمار فروش، کاربران، درآمد |

| `/addcode CODE VALUE \[percent/fixed] \[max\_uses]` | ساخت کد تخفیف |

\## ۷. 🛡 زیرساخت‌های اضافه شده



| قابلیت | توضیح |

|--------|--------|

| \*\*Task Queue\*\* | عملیات سنگین پنل در thread جداگانه — ربات هرگز بلاک نمی‌شود |

| \*\*Graceful Shutdown\*\* | با Ctrl+C ربات تمیز خاموش می‌شود |

| \*\*مانیتور انقضا\*\* | هشدار ۳ روز قبل + غیرفعال‌سازی خودکار سرویس منقضی |

| \*\*قیمت مستقل هر دسته\*\* | VIP=8000، Economic=5000، Dedicated=12000، Trade=10000 |

| \*\*چند ادمین\*\* | `ADMIN\_CHAT\_IDS` |

| \*\*حذف Rate Limiter\*\* | دیگر پیام «کمی صبر کنید» نمی‌آید |

| \*\*Markdown + هایپرلینک\*\* | لینک‌ها به صورت جمع‌وجور `\[متن](URL)` |

\## ۸. 🗄 جدول‌های دیتابیس جدید



| جدول | کاربرد |

|------|--------|

| `subscriptions` | اشتراک‌های فعال با تاریخ انقضا |

| `admin\_logs` | ثبت عملیات ادمین |

| `orders.order\_type` | تشخیص نوع سفارش: `new` / `renew` / `add\_volume` |

| `orders.renewal\_of` | اشاره به اشتراک اصلی برای تمدید/افزایش حجم |
